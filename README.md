# Coolvane HVAC — white-label template

Monorepo for the Coolvane HVAC website and operations platform.

```
apps/web        React 18 + Vite + TS — public site, customer portal, admin
apps/api        Express + TS — public content, leads, portal, secured admin API
packages/shared domain constants, zod contracts, formatting helpers
infra           reserved for deployment templates
```

## Run

```bash
npm install
npm run fonts     # self-host the typefaces (once, or after changing families)
npm run dev       # web on http://127.0.0.1:5175, api on http://127.0.0.1:4000
npm run build && npm run serve:web   # production SSR + hydration on :3000
```

- Design system: **http://127.0.0.1:5175/__styleguide** (development only, noindex)
- API health: **http://127.0.0.1:4000/api/v1/health**
- API readiness: **http://127.0.0.1:4000/api/v1/ready**

Port 5175 is used because 5173 was occupied on the development machine. Change
`server.port` in `apps/web/vite.config.ts` and the CORS origins in
`apps/api/src/server.ts` together.

## Variants

`VITE_THEME=foundry|atelier` (default `foundry`) selects the design language. In
development the floating switcher also flips it live; the choice is stored in
`localStorage` and can be forced with `?theme=atelier`.

|             | Foundry                                 | Atelier                                 |
| ----------- | --------------------------------------- | --------------------------------------- |
| Palette     | ink `#0A0D10`, frost cyan, copper ember | bone `#F5F2EC`, deep teal, burnt copper |
| Display     | Clash Display                           | Instrument Serif                        |
| Body / data | Satoshi / JetBrains Mono                | Hanken Grotesk / IBM Plex Mono          |
| Geometry    | 2px controls, blueprint grid, grain     | square controls, rules, no grid         |

## What is implemented

- Public site: home, services + 22 detail pages, products, about, process, work,
  AMC, journal, contact, quote, book, legal, 404, both themes, **/tools + six
  standalone calculator pages**.
- Admin: overview, leads, customers + full customer file, **dispatch**, **jobs
  with checklists, parts, photos and signatures**, invoices, expenses,
  team/payroll, reminders, newsletters, coupons, content studio, revisions,
  journal, media, settings, **global search (Ctrl K), CSV exports**, **RBAC users,
  permissions matrix**, **email two-factor authentication**, audit log, data
  health, GDPR erasure, backup export. Leads have suggestion search, customer
  quick-create, CSV import and branded JSON export. Customer-file equipment, AMC
  contracts, quotation lines and job reports are editable in place; PDFs are
  generated by the API.
- Customer portal: overview, bookings (book, reschedule, cancel), invoices and
  **server-generated PDFs**, quotations (accept / request changes / edit /
  **PDF**), equipment + service history, AMC cover + renewal request +
  **contract-linked upcoming visits**, job reports (checklist/**in-form photo
  uploads**), support tickets, profile, multiple sites, notification preferences
  (service, billing, AMC and marketing email), password reset, email verification.
  Quotation, AMC renewal, support, invoice and booking events respect those
  preferences and use email only.
- Operations: live admin refresh, cross-tab content sync, 10 s content polling with
  ETag/304, **server-rendered public HTML with per-route meta/JSON-LD and
  hydration**, optional prerendered fallback, same-origin sitemap/robots/feed,
  background jobs (reminders, AMC auto-visits, AMC windows, digest, backups,
  retention), paginated leads and jobs, encrypted JSON stores, record-level
  `If-Match` on content/equipment/AMC/quotation/job edits, rate limiting,
  CSP/consent, audit trail.

## Security

See `SECURITY.md`, `docs/security-verification.md` and `docs/deployment.md`.

Production requires:

```env
ADMIN_EMAIL=
ADMIN_PASSWORD=            # 12+ characters
DATA_ENCRYPTION_KEY=       # 32+ characters; keep a copy, data is unreadable without it
ALLOWED_ORIGINS=
PUBLIC_SITE_URL=
RESEND_API_KEY=            # or MAIL_WEBHOOK_URL; required for production registration/mail
PUBLIC_BRAND_NAME=         # optional; used in the 2FA email shell
DATABASE_URL=              # optional: shared PostgreSQL for multiple API instances
```

Email is the only notification channel. Admin two-factor sends a six-digit code
to the account inbox; there is no SMS provider or SMS fallback. Codes are hashed
in memory, expire after ten minutes and allow five attempts.

The JSON stores are AES-256-GCM encrypted when the key is set. Production
refuses to boot with development credentials, missing origins or no encryption
key. `npm run audit` gates high/critical advisories.

## Notes

- Fonts are self-hosted in `apps/web/public/fonts`; `scripts/fetch-fonts.mjs` regenerates them and `src/styles/fonts.css`.
- Lenis smooth scroll is disabled for coarse pointers and `prefers-reduced-motion`.
- GSAP/ScrollTrigger and three.js are client-only.
- Public routes are server-rendered for crawlers and hydrated on the client; `/admin` and `/portal` remain client-only shells. The first response carries a single `hvac-bootstrap` JSON block with content and theme, followed by hydration. Rebuild (`npm run build`) after code changes; `build:prerender` is optional and only creates static fallbacks.
- `?theme=foundry|atelier` forces the server-rendered theme and is verified for every public route by `npm run test:ssr`.
- Admin 2FA is email OTP only. Portal accounts use verified email + password and admin approval; no SMS is sent anywhere.
- One API instance is the default. Set `DATABASE_URL` for PostgreSQL-backed shared sessions, rate counters, jobs state and records; extra workers can set `JOBS_ENABLED=false` and jobs take a lease.
